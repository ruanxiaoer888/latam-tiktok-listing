# 05 宠物用品（Mascotas / Pet）

## 买家真正关心

**我家宠物多大能用**（体重/体型）→ **材质安不安全**（咬不咬得坏、会不会过敏）→ **好不好洗** → **是不是智商税**。

## 标题公式

- MX：`品类 + 适用体型/体重 + 关键材质 | 功能`
  - `Cama para Perro Talla L Lavable | 90x60 cm Antideslizante`
  - `Comedero Automático 3 L | Programable para Perros y Gatos`
- BR：`品类 + porte/peso + material | Função`
  - `Cama para Cachorro Porte Médio Lavável | 90x60 cm Antiderrapante`
  - `Comedouro Automático 3 L | Programável para Cães e Gatos`

## 必带信息（缺 → 阻断）

| 字段 | 说明 |
|---|---|
| 适用体重区间 | kg（比 S/M/L 更重要） |
| 适用体型 | MX：raza pequeña/mediana/grande；BR：porte pequeno/médio/grande |
| 颈围 / 胸围 / 长宽高 | cm |
| 材质 | 可拆洗？防滑底？无毒？ |
| 是否可机洗 | `lavable a máquina` / `lavável na máquina` |
| 电池 | 智能用品：型号、是否含、续航 |
| 适用宠物 | 犬/猫/通用 |

## 变体维度

体型/尺寸 → 颜色 → 容量

## FAQ 必问

- MX：`¿Para qué peso de perro es?` / `¿Se puede lavar en máquina?` / `¿Incluye baterías?`
- BR：`Serve para qual porte de cão?` / `Pode lavar na máquina?` / `Acompanha pilhas?`

## 合规 / 认证（这块最容易踩）

- **禁止宣称疗效**：驱虫、治病、消毒、抗过敏医疗功效 → 宠物药属受限类目（BR 需 ANVISA / MX 需 COFEPRIS）
- 含电池/蓝牙的（自动喂食器、追踪器）：BR 需 **ANATEL**，MX 需 NOM
- 材质安全：入口类（食盆、玩具）要食品级/无毒依据
- `anti pulgas` / `antipulgas` 这类词属疗效宣称，禁用

## 常见坑

1. 只写"大号"不写体重区间 → 退货
2. 体型叫法错（MX raza / BR porte）→ 一眼外国店
3. 智能用品不写电池型号 → 差评
4. 为了卖点写"抗菌/防螨"→ 违规
5. 猫犬通用不说明 → 买家买错

## 场景词

- MX：`Tu peludito lo amará`、`Cómodo y fácil de limpiar`
- BR：`Seu pet vai amar`、`Confortável e fácil de limpar`
