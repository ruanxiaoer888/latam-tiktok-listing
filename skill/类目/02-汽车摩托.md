# 02 汽车与摩托车（Autopartes y Motos / Autopeças e Motos）

## 买家真正关心

**装不装得上**（车型+年款）→ **是不是左右/前后搞反** → **OEM 号对不对** → **是否成对卖**。
这是 8 个类目里退货率最高的一个，**适配信息错一次就是一次退货 + 一个差评**。

## 标题公式

- MX：`品类 + 适配车型/年款 + 关键规格 | 位置或数量`
  - `Espejo Retrovisor Lateral Universal para Motocicleta | Par Izquierdo y Derecho`
  - `Pastillas de Freno Delanteras para Nissan Versa 2012-2019 | Juego 4 Piezas`
- BR：`品类 + 适配车型/年款 + 关键规格 | 位置或数量`
  - `Retrovisor Universal para Moto | Par Esquerdo e Direito`
  - `Pastilha de Freio Dianteira para Nissan Versa 2012-2019 | Jogo 4 Peças`

> 汽配标题允许 80–120 字符，适配信息优先于卖点。

## 必带信息（缺 → 阻断）

| 字段 | 说明 |
|---|---|
| 适配车型 | marca + modelo + año desde/hasta，**结构化**，不要写成一串文字 |
| 安装位置 | delantero/trasero、izquierdo/derecho（dianteiro/traseiro、esquerdo/direito） |
| OEM / 参考号 | 有则写，没有写 `[POR CONFIRMAR]` |
| 尺寸 | mm / cm |
| 材质 | acero、ABS、aluminio 等 |
| 数量 | 单件 / 一对 / 一套，必须明确 |
| 是否含安装配件 | 螺丝、卡扣 |

## 变体维度

左/右 → 颜色 → 尺寸 → 年款区间

## FAQ 必问

- MX：`¿Es compatible con mi [marca modelo año]?` / `¿Se vende por par o por pieza?` / `¿Incluye tornillos?`
- BR：`Serve no meu [marca modelo ano]?` / `Vem o par ou apenas uma peça?` / `Acompanha parafusos?`

## 合规 / 认证

- 不得把 OEM 号或原厂品牌写成本店品牌；只能用 `compatible con` / `compatível com`
- BR：摩托头盔 **INMETRO 强制**；灯具、刹车类法规更严；含无线（胎压监测等）加 ANATEL
- 涉及安全的件（刹车、灯光、安全带）文案不许出现"保证通过年检"之类承诺

## 常见坑

1. **适配表跨站复制**：MX 与 BR 在售车型不同（如 Onix、Gol、HB20 的分布差异很大）
2. 写 `universal` 但实际不适配 → 退货王
3. 左右件只写"一个"，买家以为成对 → 必退
4. 标题堆一堆车型关键词 → 触发堆砌降权
5. 适配表只写文字不写年款区间 → 客服每天被问"我的车能不能装"

## 场景词 / 连带销售

- MX：`Deja tu auto como nuevo`、`Para el taller o el uso diario`
- BR：`Deixe seu carro como novo`、`Para a oficina ou uso diário`
- 低客单价可加：`Lleva el par completo y ahorra` / `Leve o kit completo e economize`
