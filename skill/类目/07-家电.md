# 07 家电（Electrodomésticos / Eletrodomésticos）

## 买家真正关心

**电压/插头对不对**（错一次必退）→ **功率够不够** → **多大/多占地方** → **有没有认证**（巴西尤其）→ **保修怎么办**。

## 标题公式

- MX：`品类 + 容量/功率 + 电压 + 关键功能 | 场景`
  - `Licuadora 2 L 500 W 127V | 5 Velocidades para Cocina`
  - `Freidora de Aire 5.5 L 1500 W 127V | 8 Programas sin Aceite`
- BR：`品类 + capacidade/potência + tensão + função | Ambiente`
  - `Liquidificador 2 L 500 W 127V | 5 Velocidades para Cozinha`
  - `Fritadeira Air Fryer 5,5 L 1500 W 127V | 8 Programas sem Óleo`

## 必带信息（缺 → 阻断，绝不许猜电压）

| 字段 | 说明 |
|---|---|
| **电压 + 频率** | `127V / 60Hz`；BR 必须写明 127V 还是 220V（分区供电） |
| 功率 W | |
| 容量 L | |
| 能效等级 | BR 的 PBE 标签（大家电） |
| 整机尺寸 + 重量 | cm / kg |
| 噪音 dB | 有实测才有资格写 |
| 插头制式 | MX A/B；BR N 型 |
| 配件清单 | 杯、滤网、附件 |
| 保修期 | 必须能兑现 |
| 认证编号 | MX 标 NOM 编码；BR 标 INMETRO |

## 变体维度

容量 → 颜色 → 电压版本（BR 必分）

## FAQ 必问

- MX：`¿Funciona con el enchufe normal de 127V en México?` / `¿Cuánto consume de luz?` / `¿Incluye garantía?`
- BR：`Funciona em 127V ou 220V?` / `Consome muita energia?` / `Tem garantia?`

## 合规 / 认证（这个类目认证是第一关卡）

- MX：NOM-003-SCFI-2014；电子产品页面需标注 **NOM 认证编码**
- BR：**INMETRO 强制认证**；大家电另需 **PBE 能效标签**；插头 **N 型**；带 WiFi/蓝牙加 **ANATEL**
- 说明书、标签必须西语/葡语
- 保修承诺必须由本土售后兜得住，跨境店写"全球保修"是空头支票

## 常见坑

1. **BR 只写 `Bivolt` 不写实际范围** → 装错退
2. 插头照搬美规 → 巴西插不进
3. 页面不标 NOM 编码 → 墨西哥审核不过
4. 能效标签与页面不一致 → 违规
5. 功率/容量虚标 → 差评 + 投诉
6. 保修期乱写 → 客诉升级

## 场景词

- MX：`Ahorra tiempo en casa`、`Fácil de usar y limpiar`
- BR：`Praticidade no dia a dia`、`Fácil de usar e limpar`
