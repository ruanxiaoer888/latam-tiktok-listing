# 04 运动与户外（Deportes y Aire Libre / Esportes e Ar Livre）

## 买家真正关心

**承得住吗**（承重/耐重）→ **带出去便携吗**（重量/收纳）→ **适不适合我**（身高体重/尺寸）→ **会不会坏**（材质/防水）。

## 标题公式

- MX：`品类 + 容量/尺寸 + 关键性能 | 场景`
  - `Mochila de Senderismo 40L Impermeable | Unisex para Camping y Viaje`
  - `Mancuernas Ajustables 20 kg | Set 2 Piezas para Gym en Casa`
- BR：`品类 + 容量/尺寸 + 关键性能 | Esporte`
  - `Mochila de Trilha 40L Impermeável | Unissex para Camping e Viagem`
  - `Halteres Ajustáveis 20 kg | Kit 2 Peças para Treino em Casa`

## 必带信息（缺 → 阻断）

| 字段 | 说明 |
|---|---|
| 承重 / 阻力 | kg |
| 容量 / 展开折叠尺寸 | L、cm（`plegable` / `dobrável`） |
| 材质 | nylon、poliéster 600D、acero、TPE |
| 防水等级 | IPX 或 mm 水柱；只写"impermeable"必须有依据 |
| 适用人群 | 身高/体重区间 |
| 净重 | kg |
| 配件 | 收纳袋、防雨罩等 |

## 变体维度

尺寸/容量 → 颜色 → 阻力档位

## FAQ 必问

- MX：`¿Cuánto peso soporta?` / `¿Es plegable? ¿Qué medidas tiene cerrada?` / `¿Resiste lluvia?`
- BR：`Quanto peso suporta?` / `É dobrável? Qual o tamanho fechada?` / `Resiste à chuva?`

## 合规 / 认证

- 头盔、护具、儿童泳具/浮具属高监管：BR 摩托头盔 **INMETRO 强制**；儿童用品标准更严
- 认证宣称（`certificado`）必须有证，否则删
- 承重取保守值，不写"最大承重"给极限用法

## 常见坑

1. 防水没等级却写 `impermeable`
2. 承重按极限写，买家超载退货
3. 折叠尺寸不写 → 买家发现放不进车
4. 场景词不本地化：BR 徒步是 `trilha`，不只 `caminhada`；MX 用 `senderismo`
5. 健身器材缺"适合新手/重量档位"说明

## 场景词

- MX：`Entrena en casa o donde sea`、`Práctico y ligero`、`Ideal para camping y playa`
- BR：`Treine em casa ou onde quiser`、`Prático e leve`、`Ideal para camping e praia`
