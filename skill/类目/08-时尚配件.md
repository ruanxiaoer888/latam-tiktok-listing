# 08 时尚配件（Accesorios de Moda / Acessórios de Moda）

## 买家真正关心

**材质是不是真的**（写不锈钢实际合金=退货+投诉）→ **尺寸合不合**（周长/长度）→ **会不会过敏/掉色** → **能不能送礼**。

> 这是 8 个类目里最接近服饰逻辑的，但**仍以材质和尺寸准确为先**，不能只靠氛围图。

## 标题公式

- MX：`品类 + 材质 + 尺寸 | 场景/送礼`
  - `Collar Acero Inoxidable 45 cm | Hipoalergénico para Uso Diario`
  - `Reloj Minimalista Acero Inoxidable 38 mm | Resistente al Agua`
- BR：`品类 + material + medida | Ocasião`
  - `Colar de Aço Inoxidável 45 cm | Hipoalergênico para Uso Diário`
  - `Relógio Minimalista em Aço Inox 38 mm | Resistente à Água`

## 必带信息（缺 → 阻断）

| 字段 | 说明 |
|---|---|
| 材质 | 不锈钢 304/316L、合金、925 银、真皮、水晶玻璃 |
| 尺寸 | 链长 / 戒指周长（mm）/ 腰带长度 / 表盘直径 |
| 重量 | g（显质感，也是运费依据） |
| 是否可调节 | `ajustable` / `ajustável` |
| 是否防过敏 | 有依据才写 `hipoalergénico` |
| 镀层 | `banhado a ouro` / `chapado en oro` 必须写清厚度或等级 |
| 是否含礼盒 | 送礼场景关键 |

## 变体维度

颜色 → 尺寸（周长/长度）→ 材质版本

## FAQ 必问

- MX：`¿Se oxida con el agua?` / `¿Qué medida de cuello le queda?` / `¿Es hipoalergénico?`
- BR：`Enferruja com água?` / `Qual o comprimento do colar?` / `É hipoalergênico?`

## 合规 / 认证

- **材质不得虚标**：`aço inoxidável` / `acero inoxidable` 必须是真不锈钢
- 镀金/镀银必须写"镀"（`banhado` / `chapado`），不能写成纯金纯银
- 大牌同款/复刻 → 侵权，直接下架
- 太阳镜 `UV400` 宣称需检测依据
- 首饰里含镍的要注意 `antialérgico` 宣称

## 常见坑

1. 只写 S/M/L 不写周长 → 退货
2. 材质虚标（合金写不锈钢）→ 投诉 + 违规
3. "hipoalergénico / antialérgico" 无依据 → 违规
4. 镀金写成 "oro"（金）→ 欺诈
5. 图上是礼盒但清单没写 → 差评

## 场景词 / 连带销售

- MX：`El toque final para tu outfit`、`Ideal para regalo`
- BR：`O toque final no seu look`、`Ideal para presentear`
- 低价配件可加：`¡Pide uno para ti y otro para regalar!` / `Compre um para você e outro de presente`
