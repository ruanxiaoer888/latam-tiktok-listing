# 01 五金工具（Herramientas / Ferramentas）

## 买家真正关心

**能不能干这个活**（扭矩/功率够不够）→ **参数是不是真的**（虚标重灾区）→ **配件齐不齐**（少一个钻头就得退）→ **耐不耐用**。

## 标题公式

- MX：`核心词 + 关键规格 + 用途词 | 次卖点 + 品牌（句尾）`
  - `Gato Hidráulico de Piso 3 Toneladas para Carro | Perfil Bajo 75-500 mm ATVERCE`（78 字符）
  - `Taladro Percutor Inalámbrico 20V 13 mm para Madera y Metal | Kit 25 Piezas ATVERCE`
- BR：`核心词 + 关键规格 + 用途词 | 次卖点 + 品牌（句尾）`
  - `Parafusadeira e Furadeira de Impacto 18V 13 mm para Madeira e Metal | Maleta 25 Peças`

## 实战结论（2026-10-20，示例商品001 千斤顶实测）

| 结论 | 依据 |
|---|---|
| **用途词必须进标题**，不能只写品类 | 买家搜的是 `gato para carro`，不是只有 `gato hidráulico`；用途词放描述里拿不到搜索权重 |
| **自有品牌放句尾，不删** | 品牌占 8 字符但已有认知，且句尾不影响前 30 字符的核心词卡位；组合后 78 字符仍在上限内 |
| **60–80 是移动端建议，不是平台上限** | MX 平台上限 300、BR 200；超 80 可以，但前 40 字符必须已表达完整卖点，否则手机端只剩半句 |
| **卖点场景化 ≠ 加形容词** | 写法是"场景/利益开头 + 参数同一句"：`Sube más rápido y con menos bombeos: la bomba de doble pistón...`；不是砍掉参数去写情怀 |
| 品牌信息同时填后台 **品牌字段** | 标题有品牌 ≠ 字段可空；品牌搜索也会走属性 |

**待验证（别当定论）**：品牌句尾 vs 无品牌，谁曝光更好——用两家同定位店并行测 14 天，看曝光/点击率/转化率。

## 必带信息（缺 → 阻断，不许猜）

| 字段 | 说明 |
|---|---|
| 电压 / 频率 | 电动类：`127V / 60Hz` 或 `220V`；电池类写平台电压 `18V/20V/21V` |
| 功率 W / 扭矩 Nm / 转速 rpm | 至少一项硬指标 |
| 夹头/规格尺寸 | mm（本地不用 inch） |
| 材质 | Cr-V、S2、Acero al carbono 等 |
| 套装件数 | 与图一致，不能"约 XX 件" |
| 是否含电池/充电器 | 不含必须加粗 `NO incluidas` / `NÃO inclusas` |
| 整机重量 | kg |
| 插头制式 | MX A/B；BR N 型 |

## 变体维度

电压版本 → 套装件数 → 裸机/含电池 → 颜色

## FAQ 必问（按此顺序取 1–2 条）

- MX：`¿Funciona con el enchufe de 127V de casa?` / `¿Incluye batería y cargador?` / `¿Sirve para uso profesional o solo doméstico?`
- BR：`Funciona na tomada 127V ou 220V?` / `Acompanha bateria e carregador?` / `Serve para uso profissional?`

## 合规 / 认证

- MX：NOM-003-SCFI-2014（电动工具/电工）；页面标 NOM 编码
- BR：电动工具、电线电缆、开关插座、低压电气件多在 INMETRO 强制范围；插头 N 型；锂电 UN38.3
- 职业级宣称（`industrial` / `profissional`）必须有依据，否则删

## 常见坑

1. 标题写 inch → 本地人看不懂，也搜不到
2. 标 220V 卖到 127V 地区 → 退货 + 差评 + 安全投诉
3. "21V Reales" 这类"真实电压"反击话术，需要有依据
4. 件数虚标（图里 20 件写 25 件）→ 投诉率极高
5. 电池不含却写在包装清单里 → 必退
