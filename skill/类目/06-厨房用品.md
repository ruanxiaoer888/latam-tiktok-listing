# 06 厨房用品（Cocina / Cozinha）

## 买家真正关心

**能不能用我家灶**（燃气/电/电磁）→ **多大**（容量/尺寸）→ **材质安不安全**（涂层/不锈钢）→ **好不好洗**。

> **"是否支持 induction"不写清楚，是这个类目退货的第一大原因。**

## 标题公式

- MX：`品类 + 容量/件数 + 材质 + 适用热源 | 场景`
  - `Juego de Ollas Acero Inoxidable 12 Piezas | Apto para Inducción y Gas`
  - `Sartén Antiadherente 28 cm | Apto para Todo Tipo de Estufa`
- BR：`品类 + capacidade/peças + material + fogão | Ambiente`
  - `Conjunto de Panelas em Aço Inox 12 Peças | Compatível com Indução e Gás`
  - `Frigideira Antiaderente 28 cm | Compatível com Todos os Fogões`

## 必带信息（缺 → 阻断）

| 字段 | 说明 |
|---|---|
| 容量 | L / ml |
| 件数 | 与图一致 |
| 材质 | 304 不锈钢 / 铝合金 + 涂层 / 玻璃 / 硅胶 |
| **适用热源** | gas / eléctrica / inducción（gás / elétrica / indução），必须逐项写 |
| 耐温 | °C |
| 可洗方式 | 洗碗机可否 |
| 食品接触 | 食品级、BPA-free、PFOA-free（有依据才能写） |
| 是否含盖 | 含不含盖是差评高发点 |

## 变体维度

容量 → 件数 → 颜色

## FAQ 必问

- MX：`¿Funciona en estufa de inducción?` / `¿Se puede meter al lavavajillas?` / `¿Incluye tapas?`
- BR：`Funciona em fogão de indução?` / `Pode ir na lava-louças?` / `Acompanha tampas?`

## 合规 / 认证

- 食品接触材料合规；`libre de BPA/PFOA` 必须有检测依据
- 带电器附件（电锅、电水壶）按家电规则：BR 需 INMETRO，MX 需 NOM
- 涂层"不粘、耐刮"等性能宣称要保守

## 常见坑

1. 只写 `apto para todo tipo de estufa` 但不列具体热源 → 退货
2. 巴西感应灶普及，不写 `indução` 直接丢一半流量
3. 件数把锅盖算进去（12 件 = 6 锅 + 6 盖），必须说明
4. 涂层锅写"永不粘"→ 虚假宣称
5. 洗碗机可否不写 → 差评

## 场景词

- MX：`Ahorra tiempo en la cocina`、`Cocina como chef en casa`
- BR：`Economize tempo na cozinha`、`Cozinhe como um chef em casa`
