# 09 服装（Ropa / Roupas）——外套、风衣、衬衫外套

## 买家真正关心

**尺码准不准**（服装第一退货原因）→ **面料与厚度**（是不是说的那个）→ **版型合不合**（宽松 `holgado` / 合身 `ajustado`）→ **实物颜色与图案**（纯色还是格纹）→ **怎么洗**。

> 外套属**服装**，不是配饰：不写「配饰 / 饰品 / `accesorio`」话术。买家按「能不能穿、合不合身」决策，不按氛围图决策。

## 标题公式

- MX：`品类 + 长度/版型 + 面料 + 码段 + para… 用途词 | 品牌（句尾）`
  - `Gabardina Larga para Mujer Poliéster Tallas S-2XL para Oficina BRIGHTMOON`（73 字符）
  - `Chaqueta a Cuadros para Mujer Manga Larga Botones Tallas S-2XL Casual BRIGHTMOON`（80 字符）
- BR：`品类 + comprimento/caimento + tecido + tamanhos + para… | marca`
  - `Gabardina Longa para Mulher Poliéster Tamanhos P ao GG Trabalho BRIGHTMOON`（74 字符）
  - `Jaqueta Xadrez para Mulher Manga Longa Botões P ao GG Uso Casual BRIGHTMOON`（75 字符）

要点：

- 60–80 字符；**核心词落在前 30 字符**（品类 + 长度 + 性别），码段 `Tallas S-2XL` / `Tamanhos P ao GG` 放中后段，品牌放句尾；
- 标题必须含 `para…` 用途词（`para Oficina`、`para Uso Casual`），只写品类词拿不到搜索；
- 禁 Emoji、禁促销词；MX 用 `Tallas`、BR 用 `Tamanhos`，**不要混写**。

## 必带信息（缺 → 阻断，不许猜）

| 字段 | 说明 | 写在哪 |
|---|---|---|
| 面料成分 | `Poliéster`；属性明确写百分比才可写 `100% poliéster` | 规格区 + FAQ |
| 尺码 | S / M / L / XL / 2XL 逐码的**胸围 / 肩宽 / 袖长 / 衣长**（cm） | 尺码表（见下节） |
| 版型 | `holgado`（宽松）/ `regular`（常规）/ `ajustado`（修身） | 标题或规格 |
| 洗涤方式 | 机洗/手洗、水温、不可漂白、阴干 | 规格 `Cuidados` / BR `Cuidados` |
| 闭合方式 | 纽扣 `botones` / 拉链 `cremallera` / 无扣 | 规格 |
| 颜色 / 图案 | 纯色 `liso` / 格纹 `cuadros`；**以主图为准**，与文字冲突时按图 | 标题或规格 |
| 长度 | 长款 `largo` / 中长 `media cadera` | 标题 |
| 单件净重 | kg（运费与尺码页用） | 中文备注，不进正文 |

## 尺码表怎么写

固定 5 列，单位 cm，**必须注明手工测量误差 1–2 cm**：

| Talla | Contorno de pecho | Ancho de hombros | Largo de manga | Largo de la prenda |
|---|---|---|---|---|
| S | 92 | 37 | 57 | 79 |
| M | 96 | 38 | 58 | 80 |
| L | 100 | 39 | 59 | 81 |
| XL | 104 | 40 | 60 | 82 |
| 2XL | 108 | 41 | 61 | 83 |

BR 表头：`Tamanho` / `Busto (cm)` / `Ombro (cm)` / `Manga (cm)` / `Comprimento (cm)`

必带脚注：

- MX：`Medidas tomadas a mano, puede haber una diferencia de 1–2 cm.`
- BR：`Medidas tiradas à mão, pode haver variação de 1–2 cm.`

> ⚠️ **上表是 AXNJCPS300（长款风衣，常规版型）的实测值**，取自主图尺码表 `Guía de medidas`，用于 `output\批次20261022-AXNJC\`。
> **不得套用到 AXNJCQS502**（格纹衬衫外套，属性「包容度=宽松」）——版型不同必须单独量。
> BR 站用 P / M / G / GG 码，**换算关系待业务确认**，不得把 S–2XL 直接当巴西码写。
> 量不到就写「待确认」，**不许估、不许套用别的款**。

## 变体维度

颜色（如 AXNJCPS300 黑色 / 米色）→ 尺码 S–2XL。**尺码表按款给一份，不按颜色重复**。

## FAQ 必问（按此顺序取 ≥2 条）

- MX：`¿Qué talla me queda?` / `¿Cuánto mide el pecho de la talla M?` / `¿De qué material es?` / `¿Cómo se lava?` / `¿Es holgado o ajustado?`
- BR：`Qual tamanho devo escolher?` / `Quanto mede o busto do tamanho M?` / `De que material é?` / `Como lavar?` / `É folgado ou justo?`

优先「尺码怎么选」+「面料 / 洗涤」两条，这两条直接对应退货。

## 合规 / 认证

- **无认证编号不写认证**：服装 `certification.status = not_applicable` → Listing 不得出现 NOM / INMETRO / ANATEL / UN38.3 字样。MX 纺织品标签要求【待确认】，确认前不写任何 NOM 编号。
- **禁止绝对化承诺**：不写「绝对不改色 / 不起球 / 不缩水 / 不退色」，也不写 `no destiñe`、`no hace bolitas` 这类绝对化；只能写护理方式来降低预期落差。
- **面料不得虚标**：属性只写 `Poliéster` 就不能写 `algodón` / `lino`；百分比必须有属性依据。
- 不写医疗 / 塑形功效（`adelgaza`、`moldea el cuerpo`、`afina la figura`）。
- 防水 / 加绒 / 含帽：只有属性明确 `Es impermeable: Sí` / `Es térmica: Sí` / `Con capucha: Sí` 才能写；属性为 `No` 一律不写。
- 不写大牌同款 / 原单 / 复刻（侵权）。

## 常见坑

1. **只写 S–2XL 不写胸围 / 衣长** → 服装第一退货原因，尺码表是必带项。
2. **把 PS300 的尺码数套到 QS502** → 版型不同（常规 vs 宽松），必退。
3. **把 MX 的 S–2XL 直接搬 BR** → 巴西码是 P/M/G/GG，需换算。
4. **文字与主图冲突**：AXNJCPS300 描述里出现 `A cuadros`，但标题和主图是纯色 → **按主图写 `liso`**，冲突写进「待确认」备注。
5. **美客多字段错位**：AXNJCQS502 的 `Composición: blouses` 是字段错位 → 以 `Material principal: Poliéster` 为准，不写 blouses。
6. **外套写成配饰话术**（`accesorio` / 饰品）→ 类目与搜索全错位。
7. **写了属性为 `No` 的卖点**：AXNJCPS300 `Es impermeable: No`、`Con capucha: No`、`Es ultra liviana: No`；AXNJCQS502 `Es térmica: No`。
8. **尺码单位写 inch** → 本地读不懂也搜不到，一律 cm。
