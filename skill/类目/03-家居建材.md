# 03 家居建材（Hogar y Construcción / Casa e Construção）

## 买家真正关心

**尺寸对不对**（回家装不上就退）→ **承不承得住**（虚标就掉、就破）→ **要不要另外买配件**（螺丝/胶/工具）→ **运费**（大件）。

## 标题公式

- MX：`品类 + 尺寸 + 材质/表面处理 | 安装位置或场景`
  - `Organizador de Pared Acero Inoxidable 60 cm | 3 Niveles para Baño`
  - `Llave de Paso de Latón 1/2 Pulgada | Para Lavabo y Regadera`
- BR：`品类 + 尺寸 + 材质/ acabamento | Ambiente`
  - `Organizador de Parede em Aço Inox 60 cm | 3 Prateleiras para Banheiro`
  - `Registro de Gaveta em Latão 1/2 Polegada | Para Lavatório e Chuveiro`

## 必带信息（缺 → 阻断）

| 字段 | 说明 |
|---|---|
| 精确尺寸 | 长×宽×高，cm；含安装后外形尺寸 |
| 承重 | kg，写"建议值"而不是"极限值" |
| 材质 + 表面处理 | 不锈钢 201/304、latón、MDF、cerámica、porcelanato |
| 安装方式 | 免打孔 / 螺丝 / 落地 |
| 安装配件 | 是否含螺丝、膨胀管、胶 |
| 包装尺寸重量 | 决定运费和体积重 |
| 适用范围 | 浴室/厨房/外墙/室内 |

## 变体维度

尺寸 → 颜色/表面处理 → 套装件数

## FAQ 必问

- MX：`¿Incluye tornillos y taquetes?` / `¿Cuánto peso soporta?` / `¿Se puede instalar sin perforar?`
- BR：`Acompanha parafusos e buchas?` / `Quanto peso suporta?` / `Dá para instalar sem furar?`

## 合规 / 认证

- 承重、防水、耐火等宣称必须保守，虚标直接导致破损索赔
- 大件走体积重，物流模板必须单独配置
- 部分建材小类需资质报白，上架前先确认类目开放

## 常见坑

1. 尺寸单位混用（inch/cm）→ 装不上
2. 不写包装尺寸 → 运费算错，亏钱
3. 承重写"最大 50kg"→ 买家挂 50kg 掉下来，全责
4. 专业词不本地化：BR 用 `porcelanato`、`metalon`、`alvenaria`，MX 用 `azulejo`、`tablaroca`
5. 安装件不含却写在描述里 → 必退

## 场景词

- MX：`Renueva tu hogar sin obra`、`Fácil instalación`
- BR：`Renove sua casa sem obra`、`Instalação fácil`
