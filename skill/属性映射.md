# ML 属性 → TikTok Shop 属性槽位 映射规则（MX）

> 为什么要这层：美客多的属性名和 TikTok 后台的字段**不是一一对应**，而且 ML 属性里混着"充电器参数当产品参数"的坑。
> 直接照搬最常见的结果是：电池工具写成"127V"，家电写成"120V"，功率把充电器功率当输出功率。
> 机器实现在 `qa/map_attributes.py`，产出 `output\<批次>\属性映射.xlsx`。

---

## 1. 槽位定义（不依赖后台字段名，按语义对齐）

| 槽位 | 含义 | 典型来源 |
|---|---|---|
| `brand` | 品牌 | 属性 `Marca` |
| `model` | 型号 | 属性 `Modelo` |
| `power_type` | 供电类型：插电 / 电池 / 手动·液压 | 属性 `Tipo de alimentación`、`Es inalámbrico` |
| `voltage_battery` | **电池电压**（只有电池工具有） | `Voltaje de la batería`、标题里的 21V |
| `voltage_charger` | **充电器/额定输入电压**（MX 统一 127V） | 属性 `Voltaje`（100–240 区间） |
| `power_w` | 功率 W | 属性 `Potencia`（kW 自动 ×1000） |
| `capacity` | 容量 L / ml / Ah | `Capacidad en volumen`、`Capacidad de la batería` |
| `dimensions` | 尺寸 cm | `Largo/Ancho/Alto/Diámetro/Tamaño`，或描述里的 "Tamaño: 33*14.5*23.5cm" |
| `weight` | 重量 kg | `Peso` |
| `pieces` | 件数 | `Cantidad de piezas` |
| `material` | 材质 | `Material`、`Material de la bomba`，或描述里的 acero/aluminio/ABS |
| `package_items` | 包装清单 | 描述里的 "Lista de productos" 段 |
| `certification` | 认证编号 | **ML 没有，必须人工补** |
| `warranty` | 保修 | **人工确认** |

## 2. 五条硬规则（脚本已实现）

### 2.1 电池工具：电池电压 ≠ 充电器电压

ML 属性 `Voltaje: 127V` 对电池工具指的是**充电器输入**，不是产品电压。
→ 产品电压取 `voltage_battery`（21V 之类），`voltage_charger` 固定 127V。
→ 文案里写 `21V`，规格里可写 `Cargador: 127V`，**绝不写"127V 无线工具"**。

### 2.2 电压归一：110 / 115 / 120V → 127V

墨西哥家用标称 **127V / 60Hz**。源数据写 110V/120V 的，一律规范成 127V 并留警告（描述里的 110V 也要一并改）。

### 2.3 功率合理性闸门

- 插电类：`W ≥ 3500` 在 127V 下超过 27A，家用不合常理 → 报警，必须核铭牌（如"6800W 高压清洗机"）
- 电池类：`W ≥ 600` 多为"等效功率"或把充电器功率当输出 → 报警，不要写进卖点

### 2.4 冲突不猜

同一个槽位出现多个值（如电池电压 18V 和 21V 同时出现）→ **全部列出交人工**，脚本取不出就留空。宁可空着，不许编。

### 2.5 ML 内容清理

源描述里普遍带 `Mercado Libre`、`envío gratis`、`>299 pesos`、外链、"先联系我们再投诉"——
这些在 TikTok Shop 属于**站外导流/竞品提及**，必须全部剔除，只保留事实性内容。

## 3. 后台字段怎么绑

脚本产出的是"语义槽位"，落地到 TikTok 后台有两种方式：

1. **批量模板**：下载后台商品批量上传表，把槽位列名抄进 `qa/field_map.json`（一次配好），以后直接出上传表。
2. **单个上架**：按槽位顺序人工填，`属性映射.xlsx` 已经按槽位排好列。

> 注意：不同类目的后台必填字段不同（家电多 NOM 编码、汽摩配多适配表），这份映射只覆盖通用槽位。

## 4. 已知覆盖不到的情况

| 情况 | 处理 |
|---|---|
| 汽摩配的车型适配表 | 需要单独结构化（年款区间），脚本只提取"适配年款/位置"关键字 |
| 认证编号（NOM / INMETRO） | ML 无此字段，人工补 |
| 颜色/尺码变体 | ML `variations` 为空时无法自动出变体，需人工补 |
| 多语言（BR 站） | 槽位通用，但 `Voltaje` 口径不同（127/220 分区），需另配 BR 规则 |
