# 短视频脚本（可选模块，从 V3.2「模块 B」+ 写作指南迁入）

> **默认不生成。** 只有要做投流素材、达人寄样脚本、自播口播时才用。
> 理由：每条约多 300–600 字输出，会明显加快限额/成本消耗，而商品详情页用不到。

---

## 1. 什么时候用

| 场景 | 用不用 |
|---|---|
| 只做商品上架 | ❌ 不用 |
| 要投 TikTok 广告 / 做素材 | ✅ 用 |
| 给达人寄样要 brief | ✅ 用 |
| 自播 / 直播口播稿 | ✅ 用 |

## 2. 结构（15–30 秒）

| 段落 | 时长 | 要求 |
|---|---|---|
| 黄金 3 秒 Hook | 0–3s | 痛点冲突 / 反常识 / 对比，**第一句就要有画面** |
| 核心展示 | 3–15s | 只讲 1–2 个最强卖点，配"镜头要拍什么" |
| 信任背书 | 15–22s | 材质/认证/包装清单，压差评预期 |
| CTA | 22–30s | 指到小黄车，一句话，不喊"最后一件" |

## 3. Hook 库（MX / es-MX）

- `"3 razones por las que necesitas este {{producto}}..."`
- `"Deja de usar {{lo viejo}}, mira esto..."`
- `"Lo que pedí vs. lo que recibí en TikTok Shop..."`
- `"Nadie te dice esto antes de comprar {{producto}}..."`
- `"Si tienes {{problema}}, esto te va a ahorrar {{tiempo/dinero}}..."`

## 4. Hook 库（BR / pt-BR）

- `"3 motivos para você ter esse {{produto}}..."`
- `"Para de usar {{o antigo}}, olha isso..."`
- `"O que eu pedi vs. o que chegou do TikTok Shop..."`
- `"Ninguém te conta isso antes de comprar {{produto}}..."`
- `"Se você tem {{problema}}, isso vai economizar {{tempo/dinheiro}}..."`

## 5. CTA 库

| 站点 | 可用 | 禁用 |
|---|---|---|
| MX | `Haz clic en el carrito naranja aquí abajo`、`Compra segura`、`Revisa el enlace de abajo` | `Solo por hoy`、`Última pieza`、`Envío gratis`（未确认） |
| BR | `Toca na sacolinha laranja aqui embaixo`、`Compra segura`、`Confira o link abaixo` | `Só hoje`、`Última peça`、`Frete grátis`（未确认） |

> 橙色购物车是 TikTok 的实际形态，指代没问题；但"最后一件/仅限今日"这类虚假紧迫感在脚本里同样违规。

## 6. 脚本输出格式

```
【Hook 3s】口播：……  ｜ 画面：……
【展示 3-15s】口播：…… ｜ 画面：……
【信任 15-22s】口播：…… ｜ 字幕：……
【CTA 22-30s】口播：…… ｜ 字幕：……
（可选）B-roll 建议：……
```

## 7. 注意

- 脚本**不要**出现价格、包邮、联系方式（口播和字幕都算素材，违规一样算）
- 卖点必须和 Listing 一致，别为了视频效果夸大——买家收到货对不上就是差评
- 巴西站脚本用 `você`；墨西哥用 `tú`；两国都不要夹英文
