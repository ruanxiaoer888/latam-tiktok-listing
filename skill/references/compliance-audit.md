# 合规审计框架

> 本文件定义 Listing 合规审核的分级标准。用于人工终审、批量审计、以及 `check_listing.py` 的结果解读。
> 与 `qa/denylist.json` 的关系：denylist 做机器快筛（正则匹配），本框架做语义级审核兜底。

## 数据来源状态（Data Provenance）

标注每个关键事实的证据来源，与合规动作分开：

| 状态 | 标签 | 定义 |
|---|---|---|
| **已确认** | `CONFIRMED` | 用户明确确认、或来自铭牌/官方文档/权威第三方 |
| **图片读取** | `IMAGE_READ` | 从产品图片中识别的文字/参数，未经独立验证 |
| **推导** | `RECOMMENDED` | 基于类目惯例、同类产品、上下文推断得出 |
| **待确认** | `TO_CONFIRM` | 缺失、模糊、冲突，需要补充证据 |

> 这些状态标注在内部审核记录中，不直接出现在买家可见的 Listing 正文里。

## 合规动作分级

对每条有合规风险的表述，判定一个动作：

| 动作 | 标签 | 含义 | 处理方式 |
|---|---|---|---|
| **通过** | `PASS` | 有充分证据支持，表述准确，符合目标站点规则 | 保留 |
| **需补证** | `NEEDS_EVIDENCE` | 事实可能成立，但缺少证书/测试报告/授权文件 | 标 `[POR CONFIRMAR]`，列入待确认清单；上架前必须补齐 |
| **需改写** | `REWRITE` | 底层事实可用，但当前措辞绝对化、歧义、或超出证据范围 | 缩小到证据支持的范围内重写 |
| **删除** | `REMOVE` | 禁止内容、无事实依据、或与产品无关 | 直接删除，不留痕迹 |

### 区分原则

- 普通规格声明（如材质、尺寸、件数）：只要来源一致且不自相矛盾，可以 `PASS`，不需要独立测试
- 认证声明（NOM / INMETRO / ANATEL / UN38.3）：必须有台账记录 + 有效证书编号，否则 `REMOVE`
- 功效/安全承诺（防水等级、承重、续航时间）：需制造商文档或测试报告，否则 `REWRITE` 为保守表述
- 促销/物流承诺（包邮、时效、折扣）：需后台真实活动支撑，否则 `REMOVE`

## 严重度分级

合规动作 ≠ 严重度。同一条 `NEEDS_EVIDENCE` 可能是 Blocker 也可能是 Optimization：

| 严重度 | 定义 | 交付影响 |
|---|---|---|
| **Blocker** | 可能违规、误导、或缺少关键安全/合规要求 | P0，必须解决才能交付 |
| **Warning** | 需要补充证据或市场/类目确认 | P1，优先解决 |
| **Optimization** | 清晰度、搜索相关性、转化率改进空间 | P2，排期优化 |

## 审计报告格式

当用户请求合规审计时，使用紧凑表格：

```
| 严重度 | 合规动作 | 位置 | 问题 | 原因 | 安全改写建议 |
|--------|----------|------|------|------|--------------|
| Blocker | REMOVE | 标题 | "certificado NOM" | certification.status=missing | 删除认证词，改用通用安全表述 |
| Warning | NEEDS_EVIDENCE | 卖点3 | "resistente al agua IP67" | 无测试报告 | 改为 "resistente a salpicaduras" 或补 IP 等级证书 |
| Optimization | REWRITE | 描述首段 | "el mejor del mercado" | 绝对化用语 | 改为具体规格对比或删除 |
```

## 与现有校验脚本的关系

| 工具 | 覆盖范围 | 局限 |
|---|---|---|
| `qa/denylist.json` | 正则可判的违禁词、必带信息模式 | 无法判断语义、上下文、证据充分性 |
| `qa/check_listing.py` | P0/P1/P2 四档扫描 | 依赖 denylist，不做语义审核 |
| `qa/check_certificates.py` | 认证台账卡口 | 只查登记状态，不查表述准确性 |
| **本框架** | 语义级合规判断 | 需人工执行，不可全自动 |

建议流程：先跑脚本做机器快筛 → 再用本框架做人审兜底 → 审计结果记入批次 README。

## 目标站点差异

- **MX**：重点关注 NOM-003（127V 市电）、COFEPRIS（化妆品/食品）、西语倒标点、Tú 人称
- **BR**：重点关注 INMETRO / ANATEL / UN38.3、pt-BR 语法、você 人称、220V 电压
- 两站规则不通用，审核时必须确认目标站点

## 引用

- 常规 Listing 生成不需要输出审计报告
- 用户明确要求审计、或涉及高风险类目（电动工具/电池/化妆品/食品）时启用
- 审核结论应注明目标站点和规则版本：`审核依据：rules-mx.md v1.3 + denylist.json v1.2`
