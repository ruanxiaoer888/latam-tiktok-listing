# 转化层｜让 Listing 真的带来订单

> 合规层管「不违规」，转化层管「点进来的人为什么买」。
> 两者不冲突：**合规是地板，转化是地板之上的高度**。同样合规的两段文案，转化率能差几倍。
> 本文件只管「怎么写得让人想买」；「什么不能写」在 `rules-mx.md` / `rules-br.md` + `qa/denylist.json`。

---

## 0. 唯一验收标准

把 **标题 + 描述前两行**（手机端不点「展开」就能看到的 3 行）连起来读一遍：

> 不知道这是什么 / 不知道给谁用 / 说不出为什么要买它 → **重写**。

TikTok Shop 手机端漏斗，每层各由一个字段负责：

| 位置 | 买家心里在问 | 负责字段 | 本文节 |
|---|---|---|---|
| 主图第 1 张 | 这是什么？ | 图片 | 不在文案内（运营负责） |
| 标题（前 30 字符可见） | 是不是我要的东西？ | 标题 | §1 §2 |
| 描述前 2 行（折叠可见） | 跟我有什么关系？ | 首屏 | §3 |
| 卖点 3–5 条 | 凭什么选它？ | 卖点 | §4 |
| 规格 + 包装清单 | 能用在我场景吗？里面有什么？ | 规格/清单 | §5 |
| FAQ | 万一不合适怎么办？ | FAQ | §5 |
| 价格 / 评价 / 包邮 | 值不值、敢不敢下单？ | 后台数据 | §6 |

## 1. 关键词三层（决定「被不被搜到」）

| 层 | 内容 | 放哪 | 例（MX 五金工具） |
|---|---|---|---|
| L1 品类词 | 买家直接怎么叫这个东西 | 标题**前 30 字符** | `llave de torsión` |
| L2 用途/场景词 | 拿来干什么 | 标题前半，紧跟 L1 | `para bicicleta` |
| L3 修饰词 | 规格/材质/人群/兼容 | 标题后半 + 描述首段 | `5 Nm acero cromo` |

规则：

- **来源优先级**：TikTok 后台搜索下拉 / 同类目热卖标题 > 竞品标题 > MercadoLibre 核心词（**只兜底**）
- 两平台搜索习惯不同：ML 是「精确找型号」，TikTok 是「刷到 + 泛词搜索」，**ML 核心词不能直译过来用**
- 必须用当地叫法：MX `llave`（扳手）/ `pinza`（钳），BR `chave` / `alicate`；写错 = 搜不到
- 同一件商品在 MX 可能有两个叫法（如 `desarmador` / `destornillador`），**标题里选搜索量大的那个，另一个放描述首段**

## 2. 标题（GATE 1｜决定点击率）

必做：

1. L1 + L2 落在**前 30 字符**（手机端截断线，后面的字不一定被看到）
2. 至少一个**用途词** `para …`——只写品类词会丢掉一半搜索
3. 关键规格**只放一个**（材质 / 规格 / 数量三选一），多了变成参数堆砌
4. 品牌（有授权且自有）放句尾，不占前面黄金位

对照：

| 差 | 为什么差 | 好 |
|---|---|---|
| `Llave de Torsión 5 Nm Alta Calidad` | 无用途词；`Alta Calidad` 是空话 | `Llave de Torsión 5 Nm para Bicicleta \| Acero Cromo` |
| `Juego de Herramientas Profesional` | 无 L1 具体词、无规格、无用途 | `Juego de Llaves de Vaso 40 Piezas para Automóvil` |
| `Chave de Fenda Magnética 6 Peças` | 无场景词（para eletricista / para celular） | `Chave de Fenda Magnética 6 Peças para Eletricista` |

## 3. 首屏两行（GATE 2｜本期最关键）

描述 **第 1 行 = 钩子**，第 2 行起（第一个卖点）= 最痛的那个利益。

硬规则：

1. 第 1 行必须是**具体场景 / 具体痛点**，不是形容词
2. **禁止空泛开场**：`alta calidad` / `excelente calidad` / `perfecto para` / `ideal para` / `100%` / `ótima qualidade`
3. 西语用 `¡…!` `¿…?`；**葡语不用倒标点**
4. 第 1 行 ≤ 60 字符（再长就被折叠/截断）

改写公式：

`¿[具体烦恼]?` + `Con [产品] [怎么解决] en [场景或时间]`
（葡语去掉倒问号：`[烦恼]? Com [produto] …`）

| 空泛（✗） | 具体（✓） |
|---|---|
| `¡Herramienta de alta calidad!` | `¿Se aflojan los tornillos del sillín? Aprieta con precisión de 5 Nm sin dañar la rosca.` |
| `¡Perfecto para tu hogar!` | `¿La broca resbala en azulejo? Punta de carburo que agarra desde el primer intento.` |
| `Produto de ótima qualidade!` | `Sua chave escorrega no parafuso? Sextavado de 6 pontos que trava firme.` |

判断法：把第 1 行单独拿给一个没用过这个产品的人看，他能不能立刻想到一个自己的烦恼——想不到就是空泛。

## 4. 卖点排序（GATE 3｜决定「要不要继续读」）

按**决策权重**排，**不按参数重要性**排：

| 位次 | 写什么 | 买家真正的顾虑 |
|---|---|---|
| 1 | 解决核心痛点 / 使用场景 | 这东西能解决我的问题吗？ |
| 2 | 兼容性 / 适配范围 | 会不会买错？ |
| 3 | 材质 / 耐用 | 会不会用两次就坏？ |
| 4 | 省时省力 / 易用 | 我学得会吗？ |
| 5 | 件数 / 连带（低客单价才用） | 要不要一起买齐？ |

规则：

- 3–5 条，每条一行，单行装饰性 emoji ≤ 2
- 每条 = **利益 + 一句解释**；不写「参数：值」
- **参数一律进规格区**，不占卖点位——第一条卖点里出现 `mm / V / W / Nm / kg` 就是排错了

---

## 5. 疑虑前置（GATE 4｜同时降退货）

每个类目固定回答三问，不写就会被问、被差评、被退款：

| 疑虑 | MX 写法 | BR 写法 |
|---|---|---|
| 能不能用在我的东西上？ | `Compatible con …` / `Verifica tu modelo antes de comprar` | `Compatível com …` / `Confira seu modelo` |
| 里面到底有什么？ | `Contenido del paquete` 逐件列清楚 | `Conteúdo da embalagem` |
| 有没有隐藏成本？ | 电池/耗材是否含、是否需另购、是否含充电器 | 同 |

- 8 类目的高频疑虑见 `类目\0X-*.md` 的「疑虑清单」
- FAQ 段**至少 2 条**，优先放「兼容吗 / 含什么 / 能用在哪」这三类，不要放「质量好吗」这种自问自答

---

## 6. 权益写实（GATE 5｜合规与转化的交汇点）

原则：**后台真实存在才写；写了不许带时效承诺。**

| 可写（前提：后台真实） | 不可写 |
|---|---|
| 折扣 / 优惠券（后台已建活动） | 包邮（无实际履约能力） |
| 评价数 / 已售数（真实数字） | 时效（`llega en 24h`） |
| 多件装性价比 | 虚假紧迫（`solo por hoy` / `última pieza`） |
| 兼容清单 / 认证编号 | 绝对化（`el mejor` / `100% garantizado`） |

> `envío gratis` / `frete grátis` 属 P1「未验证承诺」，**只有店铺确实包邮才能写**，且不得叠加到货时间。

## 7. 合规替代表达（想表达但不能直说时）

| 想表达 | 不能写 | 可以写 |
|---|---|---|
| 质量好 | `calidad 100% garantizada` | `acero cromo vanadio` / `acero inoxidable 304` |
| 很耐用 | `durará toda la vida` | `resistente a 50 000 ciclos`（**有测试依据才写**） |
| 卖得最好 | `el más vendido` | 删除；改用真实评价数 |
| 马上到 | `llega en 24 horas` | 删除时效，只写 `envío por TikTok Shop` |
| 有效 / 能治 | `cura` / `elimina el dolor` | 删除；医疗宣称属受限类目 |
| 本地配送 | `desde México`（无据） | 不写产地/仓址，除非后台有本地仓 |

---

## 8. 转化自检 6 条

生成完必过；第 1/2/4/5/6 条脚本会扫（P2-转化）：

1. 标题前 30 字符是否含 **L1 品类词 + L2 用途词**？
2. 描述第 1 行是否是**具体场景/痛点**（不是形容词、不是空泛开场）？
3. **第一条卖点**是不是最痛的利益（不是参数）？
4. 卖点是否 **3–5 条**、按决策权重排？
5. 类目 3 个高频疑虑是否都回答了（兼容 / 清单 / 隐藏成本）？FAQ 是否 ≥ 2 条？
6. 写的每一项权益，后台是否**真实存在**？

## 9. 现在还不知道、必须靠数据补的

这三点**不要靠感觉拍板**：

| 未知 | 拿到数据后能做什么 |
|---|---|
| 曝光 → 点击率 → 转化率 的实际分布 | 判断该优化主图/标题（点击率低）还是描述/价格（转化率低） |
| 各词在 TikTok 搜索的真实热度 | 把 L1 从「猜」换成「有量」的词 |
| 哪种卖点顺序真的有效 | A/B：同商品两版各投 7 天，看转化差 |

> 没有数据时，按本文做**下限提升**；有数据后再做**定向优化**。
