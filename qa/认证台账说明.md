# 认证台账 + 上架卡口（v1.0）

> 2026-10-21 建立。目标：上架前能回答三个问题——**这个 SKU 在这个站点要不要认证、有没有、过没过期**。

## 文件

| 文件 | 作用 |
|---|---|
| `qa/certifications.json` | **主本**。规则（谁需要什么认证）+ 证书明细 |
| `qa/check_certificates.py` | 检查器。读 `input/*/facts.json` + 台账，出表、出 CSV、给退出码 |
| `qa/认证台账_导入模板.csv` | 导入飞书多维表格的模板（含 1 行示例，导入前删掉） |
| `qa/报告/<日期>/认证检查.csv` | 每次检查的明细（自动生成） |

## 证书字段（`certificates[]`）

| 字段 | 必填 | 说明 |
|---|---|---|
| `cert_id` | 是 | 内部唯一 ID，如 `MX-NOM003-ATVERCE-0001` |
| `site` | 是 | `MX` / `BR` / `GLOBAL` |
| `type` | 是 | `NOM-003` / `INMETRO` / `ANATEL` / `UN38.3` |
| `number` | 是 | 证书号；没有就填 `【待确认】`，检查器会标 `unverified` |
| `holder` | 建议 | 持证人（公司/工厂/品牌方） |
| `brand` | 建议 | 品牌；`skus` 和 `models` 都空时按品牌匹配 |
| `models` | 建议 | 适用型号（证书常按型号签发） |
| `skus` | 建议 | 适用 SKU；**建议逐条列明**，最不容易错 |
| `issued_at` / `expires_at` | 是 | 签发/到期日，`YYYY-MM-DD` |
| `status` | 是 | `valid` / `replaced` / `revoked` |
| `source_url` | 是 | 证书查询页或认证机构链接 |

**匹配顺序**：SKU 精确匹配 → 型号匹配 → 品牌匹配（品牌匹配会在结果里标 `match_by=brand`，提醒你确认）。

## 怎么加一张证书

```json
{
  "cert_id": "MX-NOM003-ATVERCE-0001",
  "site": "MX",
  "type": "NOM-003",
  "number": "NYCE-XXXXXXXX",
  "holder": "ATVERCE SA DE CV",
  "brand": "Atverce",
  "models": ["A+D+1", "ABU5000000"],
  "skus": ["ABU5000000"],
  "category": "五金工具",
  "issued_at": "2025-03-01",
  "expires_at": "2028-03-01",
  "status": "valid",
  "source_url": "https://www.nyce.org.mx/",
  "verified_at": "2026-10-21",
  "notes": ""
}
```

## 怎么跑

```powershell
cd qa
python check_certificates.py --demo                              # 自检（不需要 input）
python check_certificates.py --input-root ..\input               # 默认 auto：按 facts 的 site_profiles 检查
python check_certificates.py --input-root ..\input --site ALL    # 双站规划口径（MX+BR 都查）
python check_certificates.py --input-root ..\input --strict      # 有阻断项 → 退出码 3（接 CI/上架卡口）
python check_certificates.py --input-root ..\input --days 90     # 换证提醒窗口改成 90 天
```

**退出码**：`0` 正常；`2` 台账/输入文件有问题；`3` `--strict` 且有阻断项。

**状态**：`valid` 有效 / `expiring` 即将到期（窗口内）/ `expired` 已过期 / `unverified` 缺证书号或有效期 / `missing` 台账里根本没有。

## 飞书多维表格导入

1. 打开「认证台账」表（新建，或放在产品知识库同一空间）
2. 导入 `qa/认证台账_导入模板.csv`（UTF-8，飞书会自动识别列名）
3. 删掉示例行，按证书逐条填
4. 每季度核对一次，更新 `最后核对日期`，并在 `qa/certifications.json` 的 `changelog` 记一笔

> 本地 `certifications.json` 是主本；飞书表是给人看/审核的视图。两边不要各改各的——**证书变更先改 JSON，再同步飞书**。

## 已知边界（别指望它做）

- 不校验证书**真伪**，只校验「有没有登记、过没过期」；真伪去认证机构官网查
- INMETRO 对锂电工具的适用范围**待确认**，现在是提醒不是阻断
- UN38.3 是**运输**要求，报告必须第三方实验室出，台账只记编号和有效期
- 各类目在 TikTok Shop MX/BR 的**类目准入**要登录 Seller Center 看，公开页拿不到
